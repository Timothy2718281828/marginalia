## 本书特点

施里亚耶夫的《概率论》是 Springer GTM 系列中的经典：

- 基于**测度论**的严格概率论体系
- 从 Kolmogorov 公理化出发
- 对随机过程（特别是随机游走、Martingale、Markov 链）有深入讨论
- 习题设计精妙，与金融数学、统计推断有紧密联系
