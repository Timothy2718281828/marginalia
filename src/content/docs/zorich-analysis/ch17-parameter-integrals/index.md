## Chapter 17: Integrals Depending on a Parameter

Proper parameter integrals (continuity, differentiation, integration under the integral sign), improper parameter integrals (uniform convergence with respect to the parameter, limit transitions), Euler integrals (Beta and Gamma functions), convolution of functions, the Weierstrass approximation theorem via delta-type families, and an introduction to distributions.
